# NutriMeal

Локальный PWA-трекер питания: дневник, каталог продуктов и рецептов, планирование, профиль и статистика.

## Статус проекта

- `index.html` запускает новый runtime напрямую и является production-точкой входа.
- `app-preview.html` использует тот же runtime для интеграционной проверки.
- `PWA_v60_code_blocks.html` сохранён как legacy-референс и fallback.
- Основной план миграции завершён. Последующие улучшения и отдельно отложенные решения перечислены в [плане](./план.md).
- Дневник, план, наборы, профиль и история тела сохраняются через repositories. Каталог продуктов, рецептов и подборок пока живёт только в памяти; см. [архитектурное описание](./АРХИТЕКТУРА-ПРИЛОЖЕНИЯ.md).

## Запуск и проверка

```powershell
npm run preview
npm test
```

`npm run preview` запускает локальный сервер, а `npm test` выполняет набор тестов на Node.js.
