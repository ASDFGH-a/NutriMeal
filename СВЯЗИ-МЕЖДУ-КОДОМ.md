# Связи между частями кода

## Система связей

В таблицах ниже указаны:

- входной модуль;
- используемые модули;
- зависимый результат;
- сохранение или побочный эффект.

| Файл | Связан с | Назначение связи |

| `src/contracts/mass-entry.contract.js` | `mass-entry.js` | Ограничивает source, preview и result |
| `src/contracts/nutrition-set.contract.js` | nutrition-set use cases | Проверяет set array/repository/результаты |

## Application

| Use case/service | Вызывает domain | Вызывает contract | Сохраняет через |
|---|---|---|---|
| `save-product` | `normalizeProduct`, nutrient calculation | Catalog contract | Непосредственно не сохраняет; возврат state |
| `save-recipe` | Recipe defaults/model/nutrient calculation | Catalog contract | Непосредственно не сохраняет |
| `delete-product` | Recipe model | Catalog contract | Непосредственно не сохраняет |
| `collections` | collection.model | Catalog contract | Непосредственно не сохраняет |
| `add-food-entry` | `createFoodDiaryEntry` | Diary contract | Переданный diary repository |
| `update-food-entry` | diary-entry/date/rules | Diary contract | Переданный diary repository |
| `replace-food-entry` | diary-entry/rules | Diary contract | Переданный diary repository |
| `remove-food-entry` | Нет отдельной фабрики | Diary contract | Переданный diary repository |
| `add-water-entry` | `createWaterEntry` | Water contract | Переданный water repository |
| `weight/weight-history` | weight-history model | Body-history contract | Weight + profile repositories |
| `measurement/measurement-history` | measurement model | Body-history contract | Measurement + profile repositories |
| `plan.js` | plan model/calculation | Planning contract | Вызывается legacy/UI |
| `plan-presets.js` | plan model | Planning contract | Через legacy storage workflow |
| `nutrition-sets.js` | nutrition-set model/calculations | Nutrition-set contract | Set и active-set repositories |
| `mass-entry.js` | diary-entry/nutrients/mass-entry model | Diary + mass-entry contracts | Diary repository |
| `get-diary-statistics.js` | nutrition-set/statistics models | Statistics contract | Нет записи |
| `initialize-core-data.js` | catalog/profile/plan/nutrition-set/measurement | Storage contract | Создаёт и обновляет repositories |

## Legacy-связи

| Legacy-файл | Связи |
|---|---|
| `PWA_v60_code_blocks.html` | Читает localStorage, содержит глобальное UI-состояние, вызывает старые render/open-функции и новые UI-модули |
| `PWA_v60_code_blocks.html` -> `src/ui/` | Подключает UI-модули и передаёт им данные |
| `PWA_v60_code_blocks.html` -> `src/application/` | Использует динамические ES-модули веса и замеров |
| `PWA_v60_code_blocks.html` -> `src/infrastructure/` | Использует repositories для веса/замеров |
| `index.html` | Показывает legacy-файл через iframe |
