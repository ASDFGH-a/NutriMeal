## 2. Подтверждённая структура исходного интерфейса

## 3. Классификация строк

Каждый кандидат относится к одной из категорий:

- **UI_STATIC** — фиксированная подпись, заголовок, кнопка, подсказка, уведомление или текст пустого состояния. Может попасть в словарь.
- **UI_ENUM** — фиксированное значение справочника/перечисления, показываемое пользователю (например, тип активности или категория). Переводится только на UI-границе; исходное значение в данных не меняется.
- **USER_DATA** — имена продуктов/рецептов, заметки, ингредиенты, произвольные категории и теги пользователя, записи дневника, профильные значения. Не переводить автоматически.
- **NUTRITION_DATA** — названия нутриентов, единицы, названия стандартных измерений и другие предметные справочные значения. Отдельно проверить контекст отображения и согласованность обозначений.
- **TECHNICAL** — ключи, идентификаторы, имена функций, storage keys, CSS-классы, диагностические сообщения для разработчика. Не включать в пользовательский словарь без отдельного основания.
- **DYNAMIC_TEMPLATE** — фраза с переменными. Переводить как целый шаблон с явно заданными параметрами, не заменять отдельные слова внутри готовой строки.

## 4. Правила словаря

- Ключ словаря — точная исходная русская UI-строка, без `toLowerCase()` и без частичных замен.
- Значение — полный английский эквивалент.
- Для неизвестного ключа возвращается исходная строка.
- Пользовательские данные не проходят через словарь автоматически.
- HTML-разметка, числа, идентификаторы, единицы измерения и динамические значения не должны повреждаться переводом.
- Перевод атрибутов ограничивается подтверждёнными UI-атрибутами; значения пользовательских полей и данные не переводятся.
- Короткие и неоднозначные слова нельзя глобально заменять внутри предложений.
- Если одна и та же русская строка используется и как UI-метка, и как значение данных, решение принимается по месту отображения; словарь не мутирует исходное значение.

## 6. Границы этапа

- Не менять исходный HTML v60.
- Не интегрировать словарь в `translateText()` или `applyI18n()` на этом этапе.
- Не реализовывать переключение/восстановление языка (это R05-B3).
- Не переводить пользовательские записи, названия продуктов/рецептов и произвольные пользовательские категории.
- Не объявлять английскую локализацию завершённой после создания словаря.
- Не удалять старый UI-код и не менять storage keys.
