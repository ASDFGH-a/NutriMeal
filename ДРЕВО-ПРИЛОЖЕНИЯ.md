# Древо приложения NutriMeal

## Корень

```text
NutriMeal/
├── index.html                         # Текущая точка отображения приложения через iframe
├── PWA_v60_code_blocks.html           # Legacy runtime; совместимый временный backend/UI монолит
├── package.json                       # ESM-проект и команда node --test
├── план.md                            # План миграции по девяти пакетам
├── Зависимости фул.md                 # Карта зависимостей исходного приложения
├── Таблички приложения.md             # Формулы и правила статистики
├── src/                               # Новая архитектура приложения
└── tests/                             # Node test suite
```

## `src/contracts/`

Публичные контракты и порты слоёв.

```text
src/contracts/
├── body-history.contract.js           # Запросы и результаты истории веса/замеров
├── catalog.contract.js                # Контракты каталога, подборок и CRUD
├── diary.contract.js                  # Запись, замена, редактирование и удаление в дневнике
├── mass-entry.contract.js             # Preview и apply массовой записи
├── nutrition-set.contract.js          # Наборы питания и активный набор
├── planning.contract.js               # Расчёт плана и пресеты
├── statistics.contract.js             # Запрос и результат статистики
├── storage.contract.js                # Storage и repository-порты
└── water.contract.js                  # Контракт добавления воды
```

## Не перенесённые участки legacy runtime

Следующие области пока находятся в `PWA_v60_code_blocks.html`:

- редакторы Рецептов и Продуктов;
- редактор состояния карточек Каталога;
- полный список фильтров и категорий Каталога;
- модальные окна Дневника;
- массовая запись;
- полное редактирование Планирования;
- часть сценариев наборов питания и редакторы недель;
- часть обработки локализации;
- общая точка входа без iframe.

Они являются временно активным runtime и не должны удаляться до интеграционной проверки соответствующих UI-сценариев.
